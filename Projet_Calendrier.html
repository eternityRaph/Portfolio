Projet : création d'un ChatBot

<- Retour

Statut : en cours

En BUT, par groupe de 5, nous avions pour but de développer une application de gestion d’évènements en prévoyant les contraintes et les risques, en réalisant les différents diagrammes de conception (diagrammes de classes et de séquences) avant de passer au développement de l’application.

Cette application devait contenir tous les attendus d’une application de gestion d’évènements : créer un évènement, voir les détails d’un évènement, etc. Pour mon groupe, il s’agissait de créer une application de gestion de voyages scolaires, donc nous devions prendre en compte le budget de l’établissement, les effectifs de classe, le type de voyage, le lieu, etc.

Dans ce projet, je me suis occupé principalement de la réalisation des diagrammes de conception et m’occupe actuellement d’une partie du développement de l’application.

  • Rôle dans le projet : réalisation des diagrammes de conception (Use Case, diagramme de classe, etc.)
  • Durée du projet : 3 mois
  • Compétences acquises : prise en main de Visual Paradigm
